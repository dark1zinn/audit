# audit

A free, open-source (Apache 2.0), self-hostable team platform: kanban boards, channels and threads,
live co-edited docs and calendars in one workspace, where every item can link to every other.

- **One install, one workspace** for teams of 5–200 people: one container plus PostgreSQL behind
  one domain.
- **Fine-grained permissions** with project-scoped teams, and every change recorded in a
  tamper-evident audit log.
- **Optional AI** that uses your own provider keys, acts with the requesting user's permissions and
  never writes without approval.
