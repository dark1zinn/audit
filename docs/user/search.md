# Search and command palette

## Command palette

Press `Ctrl+K` (or `⌘K` on macOS) to open the palette.

- With an empty query it lists your recent items.
- Typing shows up to 20 results across tasks, documents, channels, projects and events.
- The **Actions** group creates a task, creates a document, creates an event, opens My tasks, or
  opens the inbox.
- Theme and language switches are also in the palette.

Results are limited to what you can see.

## Search page

Open **Search** for full results. Filter by type (task, doc, message, channel, event, person, team,
project), project, author, updated date range, and "mentions me". Results load in pages of up to 50.

Searchable content: task keys and descriptions, project keys and names, channel names and topics,
event descriptions and locations, messages, comments, and document text. Files are not searched.

Search uses full-text matching, falling back to fuzzy matching. When the AI semantic-search feature
is on and an embedding provider is configured, results are combined with meaning-based matches.

Admins can rebuild the search index from the admin Maintenance page.
