# Inbox and notifications

The inbox lists notifications, newest first, up to the latest 100.

## Kinds

Tasks (due soon, overdue, assigned, unassigned, changed), mentions, direct messages, thread replies,
comments, document review due, invitations accepted, calendar invitations and changes, event
reminders, and AI proposals.

## Channels

Each kind can be sent to three channels: **in-app**, **push** (browser Web Push), and **email**.
Everything is on by default; turn kinds off per channel under **Settings → Notifications**.

- In-app notifications are not delayed.
- Push and email are delayed until quiet hours end.
- Push needs a browser subscription on the notifications settings page.
- Email is only available when the operator has configured SMTP.

## Quiet hours

Set a start and end time in your timezone. Ranges can cross midnight.

## Folding

Several notifications of the same kind for the same item within five minutes are folded into one
inbox row with a count.

## Actions

Mark as read or unread, archive, unarchive, or mark all as read. Keyboard: `r` toggles read,
`e` archives the selected item.

A notification is shown only while you still have access to the item it refers to.
