# 0001 — Bun dependency check

Status: accepted · 2026-11-19

Phase 0 week 1 checked every dependency the plan names on Bun 1.4.4 before code depended on it.
Each item below was executed in a scratch project; the patterns that worked are now in the codebase.

| Dependency                                                          | Result on Bun                                                                                                                                                                                                                                                             | Decision                                                                                                                                      |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Effect 4.1.4 (`effect/http-api`, `effect/rpc`, `effect/sql`)        | Works. `HttpRouter.toWebHandler` runs under a plain `Bun.serve`; RPC over WebSocket needs a small bridge because `request.upgrade` is unavailable outside Effect's own Bun server (`apps/server/src/websocket.ts`).                                                       | Adopted.                                                                                                                                      |
| `@effect/sql-pg` 4.1.4                                              | Works. No codec for `tsvector`, so a read-only codec is registered (`packages/platform/src/pg-types.ts`). Role switching through the `role` startup parameter works.                                                                                                      | Adopted.                                                                                                                                      |
| Drizzle 1.0.0-rc.5 Effect driver                                    | Works. Drizzle and raw `SqlClient` statements share one transaction; nested transactions are savepoints. The Effect migrator needs one statement per `--> statement-breakpoint` chunk. `drizzle-kit` runs as `bunx --bun drizzle-kit`.                                    | Adopted, pinned exactly. Fallback (Effect's SQL client) stays available.                                                                      |
| Better Auth 1.7.26                                                  | Works with the Drizzle adapter over `drizzle-orm/bun-sql`. Password hashing is overridden to argon2id via `Bun.password`; TOTP, backup codes, passkeys and database rate limiting work. No native idle timeout: enforced per request.                                     | Adopted. Tables are owned by Drizzle migrations (one migration system).                                                                       |
| pg-boss 12.38.2                                                     | Works on its own pool. `send` joins an Effect transaction through a custom `executeSql` adapter that captures the fiber context inside the transaction. Cron and graceful stop work.                                                                                      | Adopted.                                                                                                                                      |
| Hocuspocus 4.8.0                                                    | `Hocuspocus.Server` binds `node:http` and cannot be used; the `Hocuspocus` class with `handleConnection` works. Through crossws, the proxied socket breaks `send` and needs a wrapper.                                                                                    | Use `handleConnection` directly on Bun's native WebSocket handler (the one `Bun.serve` already dispatches for `/rpc`); crossws is not needed. |
| Tiptap 3 headless + `@hocuspocus/transformer`                       | Works: schema, Yjs ↔ ProseMirror JSON round trip, mention extraction.                                                                                                                                                                                                     | Adopted for server-side document parsing.                                                                                                     |
| Image thumbnails                                                    | `sharp` works at runtime but its native binding is not embedded by `bun build --compile`. Bun's built-in `Bun.Image` (static JPEG/PNG/WebP codecs, resize, EXIF orientation, pixel limits) decodes, resizes and encodes WebP and PNG at runtime and in a compiled binary. | `Bun.Image`: no native dependency.                                                                                                            |
| `file-type`                                                         | Works for MIME sniffing from buffers.                                                                                                                                                                                                                                     | Adopted.                                                                                                                                      |
| Vite 8, React 19, TanStack Router, Tailwind 4, shadcn CLI, Lingui 6 | All run under `bunx --bun` without Node. Lingui 6 uses its native macro transform (no Babel).                                                                                                                                                                             | Adopted.                                                                                                                                      |
| Playwright 1.65                                                     | The runner works under Bun. The bundled Chromium cannot start on NixOS (missing system libraries).                                                                                                                                                                        | The Nix dev shell provides `playwright-driver.browsers` and sets `PW_CHROMIUM`; CI on Ubuntu uses the bundled browser.                        |

## Other decisions taken during the check

- **Better Auth admin plugin is not enabled.** Its endpoints would change roles, ban users and revoke
  sessions outside the command layer and the audit log. The admin console uses audited commands
  instead (`packages/core/src/identity/commands.ts`).
- **Database roles.** `DATABASE_MIGRATOR_URL` (the owner login) runs migrations, pg-boss setup, backup, and restore. `DATABASE_URL` is the app login `audit_app`, which cannot delete audit trail rows. Retention deletes rows only through the `trail_purge` function.
